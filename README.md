## 📂 Projects

### [rv32i-alu](https://github.com/gurleenkaurrrr/rv32i-alu)
Python-based automated test framework as a golden model for a 10-operation ALU — 26 directed test vectors, 100% match between software reference and hardware simulation, full verification reports. *Spring 2026*

### [mac-processing-element](https://github.com/gurleenkaurrrr/mac-processing-element)
8-bit multiply-accumulate PE in VHDL mirroring TPU/Tenstorrent-style AI accelerators — structured automated testbench, all tests passing on GHDL. *Spring 2026*

### [microcoded-processor-fpga](https://github.com/gurleenkaurrrr/microcoded-processor-fpga)
General-purpose microcoded processor in VHDL — custom 9-operation ALU, 9-state Moore FSM sequencer, 4×16 decoder, 7-segment display output. Synthesized and deployed on Intel FPGA. *COE328 · Fall 2024*

### [bookstore-application](https://github.com/gurleenkaurrrr/bookstore-application)
Java desktop bookstore management system — layered MVC architecture, State Pattern loyalty rewards system, Singleton pattern, Java Swing GUI. *COE528 · Winter 2025*

### [noaa-ice-analysis-c](https://github.com/gurleenkaurrrr/noaa-ice-analysis-c)
C program analyzing 3 years of real NOAA Great Lakes ice concentration data — statistical analysis with structs, pointers, file I/O, and GNUPlot visualizations. *CPS188 · Winter 2025*
